# 가상 예제 연습 — 자기소개서

> 이 문서의 회사·인물·경험은 모두 가상이다. 실제 지원에 사용하지 않는다.

## 문항 1 — 지원 동기와 입사 후 하고 싶은 일 (최소 100자, 최대 300자)

사용자의 요청을 안정적으로 처리하는 서비스를 만들고 싶어 모래시계테크에 지원했습니다. 우체통 알림 서비스에서 Python과 FastAPI로 알림 설정 API를 개발하고 PostgreSQL 스키마를 설계했습니다. 이 경험은 공고의 API 개발과 데이터 모델링 업무와 맞닿아 있습니다. 입사 후에는 요청 흐름을 먼저 이해하고 테스트로 변경의 영향을 확인하는 개발자가 되겠습니다.

## 문항 2 — 문제를 발견하고 해결한 경험 (최소 100자, 최대 300자)

개발 중 같은 알림이 두 번 저장되는 문제가 생겼습니다. 재현 요청을 만든 뒤 로그를 비교해 재시도 과정에서 동일 요청이 반복된다는 점을 확인했습니다. 요청 식별자를 기준으로 중복 저장을 막고 해당 경로를 검증하는 통합 테스트 12개를 작성했습니다. 이 경험으로 오류를 재현하고 원인을 확인한 뒤 검증을 남기는 습관을 익혔습니다.
