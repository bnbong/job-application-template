## 프로젝트

### 우체통 알림 서비스

- 기간: 2026.03~2026.06
- 구성: 3인 팀 프로젝트
- 역할: 알림 설정 API 개발, PostgreSQL 스키마 설계
- 기술: Python, FastAPI, PostgreSQL
- 문제 해결: 같은 알림이 두 번 저장되는 문제에 재현 요청을 만들고 로그를 비교했다. 재시도 과정에서 동일 요청이 반복되는 원인을 확인하고 요청 식별자를 기준으로 중복 저장을 막았다.
- 검토한 대안: 알림 테이블에 유일 제약을 걸어 저장 자체를 막는 방법을 검토했으나, 재시도는 허용해야 해서 요청 식별자로 걸러내는 방식을 선택했다.
- 확인 가능한 결과: 같은 재현 절차에서 저장 건수가 2건에서 1건으로 줄었다.
- 검증: 해당 경로를 검증하는 통합 테스트 12개 작성
- 근거: 가상 예제 연습을 위해 작성한 이 문서
